1. Descripción del Caso Problema

La empresa RiTech SAS solicita una solución de software para llevar a cabo exportaciones de café y de cacao a los países de la Unión Europea. Este proyecto requiere el desarrollo de una plataforma web que permita gestionar de manera integral todo el proceso de exportación, desde la selección y preparación de los productos hasta su entrega en los mercados europeos.

El sistema debe contemplar múltiples funcionalidades que incluyen, pero no se limitan a: gestión de inventarios, controles de calidad, seguimiento de transporte, registro de exportaciones, administración de usuarios y toma de decisiones de inversión. La plataforma busca optimizar los procesos operativos de la empresa y garantizar el cumplimiento de las normativas internacionales de comercio de productos agrícolas.

2. Product Backlog

El product backlog fue elaborado siguiendo la primera ceremonia de la metodología Ágil, en la cual se listan todos los elementos necesarios para construir el software solicitado.

2.1 Stack Tecnológico Seleccionado

Capa Tecnología Justificación
Frontend Next.js (o Vite+React) + Tailwind CSS + shadcn/ui + Motion (Framer Motion) Para secuencias de scroll complejas se utilizará GSAP de forma puntual
Backend NestJS (TypeScript + Node.js) Framework robusto y escalable para APIs RESTful
Base de datos PostgreSQL Fiabilidad, soporte JSON, consultas complejas para reportes
Autenticación Passport.js con JWT o Clerk/Supabase Gestión segura de sesiones
ORM Prisma ORM o TypeORM Interacción tipada y segura con la base de datos

2.2 Elementos del Backlog

2.2.1 Módulo de Gestión de Usuarios

  • Registro de usuarios (clientes, vendedores, administradores)
  • Inicio de sesión con autenticación JWT
  • Gestión de roles y permisos (Administrador, Vendedor, Cliente, Operador de Logística, Inspector de Calidad)
  • Perfil de usuario con información personal y empresarial
  • Recuperación de contraseña

2.2.2 Módulo de Inventario

  • Registro de productos (café y cacao, con variedades y presentaciones)
  • Control de stock disponible para exportación
  • Gestión de lotes por finca o proveedor
  • Alertas de inventario bajo
  • Historial de movimientos de inventario
  • Clasificación de productos por calidad (especial, superior, estándar)

2.2.3 Módulo de Exportaciones

  • Creación y registro de órdenes de exportación
  • Selección de productos y cantidades para exportar
  • Documentación requerida (certificados de origen, certificados fitosanitarios, facturas comerciales, listas de empaque)
  • Gestión de destinos (países de la Unión Europea)
  • Cálculo de costos de exportación (flete, seguros, aranceles)
  • Seguimiento del estado de cada exportación (pendiente, en proceso, embarcada, en tránsito, entregada)
  • Registro de cantidades mínimas para iniciar una exportación

2.2.4 Módulo de Controles de Calidad

  • Registro de inspecciones de calidad pre-exportación
  • Parámetros de calidad (humedad, defectos, pureza, tamaño de grano)
  • Generación de certificados de calidad
  • Control de calidad post-exportación (recepción en destino)
  • Historial de controles de calidad por lote

2.2.5 Módulo de Transporte y Seguimiento

  • Registro de medios de transporte (marítimo, aéreo, terrestre)
  • Seguimiento en tiempo real del estado del producto durante el transporte
  • Estimación de tiempos de entrega
  • Gestión de empresas de logística asociadas
  • Registro de condiciones de transporte (temperatura, humedad en contenedor)
  • Notificaciones de cambios de estado

2.2.6 Módulo de Dashboard y Toma de Decisiones

  • Panel principal con métricas clave de exportaciones
  • Gráficos de rendimiento de ventas por producto y región
  • Comparativa de inversiones (simulación de comportamiento NASDAQ 100)
  • Reportes de exportaciones históricas
  • Exportación de reportes en PDF y Excel

2.2.7 Módulo de Interfaz de Vendedores

  • Publicación de productos por parte de vendedores independientes
  • Sistema de comisiones por ventas a través de la plataforma
  • Gestión de pedidos recibidos
  • Chat o mensajería entre vendedores y compradores

2.2.8 Infraestructura y Seguridad

  • Configuración de servidor NestJS con PostgreSQL
  • Implementación de Passport.js con JWT para autenticación
  • Cifrado de datos sensibles
  • Respaldo automático de la base de datos
  • Despliegue en la nube (AWS, Vercel, o similar)
  • Documentación de la API (Swagger)

3. Preguntas del Equipo

Las siguientes preguntas fueron formuladas durante la ceremonia de análisis del caso problema:

3.1 Preguntas sobre Exportaciones

  • ¿Cuál es la cantidad mínima con la que se inicia una exportación?
  • ¿Cuántos tipos de exportación de cacao se darán?
  • ¿Qué información se necesita para registrar cada exportación?
  • ¿Cómo se llevaría a cabo el transporte para los productos?
  • ¿Es necesario tener un seguimiento de cómo es el estado del producto mientras se esté transportando?

3.2 Preguntas sobre Vendedores y Comisiones

  • ¿Un vendedor podría vender su cacao a través de la página de la empresa dándole un porcentaje de comisión a esta empresa?
  • ¿Qué comisión porcentaje se cobraría por cada venta realizada a través de la plataforma?
  • ¿Qué requisitos debe cumplir un vendedor para registrarse en la plataforma?

3.3 Preguntas sobre Inventario y Calidad

  • ¿Cómo se manejaría el inventario general que esté disponible para exportación?
  • ¿Cómo se realizarían los controles de calidad antes y después de exportar los productos?
  • ¿Qué parámetros de calidad se evaluarán en el café y cacao?

3.4 Preguntas sobre Administración

  • ¿Quién sería el encargado de administrar el sistema?
  • ¿Qué funciones podría realizar cada tipo de usuario dentro de la plataforma?
  • ¿Qué permisos tendría cada rol de usuario en el sistema?

5. Conclusiones

El análisis del caso problema de la empresa RiTech SAS permitió identificar las necesidades principales para el desarrollo de una plataforma web de exportación de café y cacao a países de la Unión Europea. A través de la metodología Ágil, se logró definir un product backlog completo que contempla los módulos necesarios para la gestión integral del proceso de exportación.

Las preguntas formuladas por el equipo sirvieron como base para comprender mejor los requisitos del sistema, abarcando aspectos como las cantidades mínimas de exportación, los controles de calidad, el seguimiento de transporte, la gestión de inventarios y los roles de usuario. El stack tecnológico seleccionado (Next.js, NestJS, PostgreSQL, Passport.js y Prisma ORM) proporciona una base sólida y escalable para el desarrollo del proyecto.

La experiencia de trabajo en equipo durante las primeras jornadas del proyecto demuestra la importancia de la comunicación constante y la organización de las tareas para el logro de los objetivos propuestos.
